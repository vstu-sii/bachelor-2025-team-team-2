# D4 — RACI Matrix

Матрица ответственности по задачам проекта. В ней видно, кто выполняет работу (R), кто отвечает (A), кто консультируется (C) и кто информируется (I).

| Область ответственности | SA/PO | AI Eng | MLOps | Fullstack |
| --- | --- | --- | --- | --- |
| Постановка задачи и требования | A/R | C | I | I |
| Разработка AI-модели | C | A/R | C | I |
| Сбор и обработка данных | C | R | A | I |
| Настройка ML-пайплайна | I | C | A/R | I |
| Разработка фронтенда (UI) | I | I | I | A/R |
| Интеграция AI в приложение | C | R | C | A |
| Тестирование | C | R | C | A |
| Документация | A | I | I | R |
| Презентация проекта | A | C | I | R |
| Коммуникация с ментором | A | I | I | I |

## Decision Making Process
Финальное слово при конфликтах — SA/PO. Это позволяет избежать спорных ситуаций и ускоряет принятие решений.

## Escalation Path
1. Обсуждение внутри команды
2. Решение SA/PO
3. Эскалация к ментору
