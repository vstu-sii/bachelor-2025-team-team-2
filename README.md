## О проекте

Категория: бытовая техника / домашний ассистент.

`Cleaning Assistant` — приложение, которое с помощью искусственного интеллекта анализирует качество уборки по фотографиям и выдает объективную оценку с рекомендациями по улучшению.

## Цель

Создать приложение, которое с помощью AI анализирует качество уборки по фотографиям и дает объективную оценку.

## Сегменты пользователей

1. **Родители с детьми** — хотят приучить детей к порядку.
   Пример: «Ребенок убрал комнату — сфотографировал, получили оценку, поощрили».
2. **Работающие взрослые (25–50 лет)** — хотят быстро проверить уборку.
   Пример: «Пришел с работы, сфотографировал комнату — узнал, нормально ли убрали».
3. **Клинеры и уборщики** — показывают клиентам результат.
   Пример: «Сделал уборку — показал клиенту оценку от приложения».

## Pain Points (основные проблемы пользователей)

- Не понимаю, нормально ли убрали или нужно переделывать
- Нет времени и сил проверять каждую полку и угол
- Постоянные споры дома из‑за качества уборки
- Детям неинтересно убираться — нет понятной системы оценки
- Не доверяю клинерам — переживаю, что они плохо убрали

## Use-cases

1. Проверить уборку: сфотографировал комнату → получил оценку → узнал, что улучшить
2. Мотивировать детей: ребенок убрался → сделал фото → получил оценку → получил похвалу
3. Показать качество работы: клинер убрал → сделал фото → показал клиенту отчет → получил оплату

## Value Proposition

`Cleaning Assistant` использует искусственный интеллект для мгновенной объективной оценки качества уборки, превращая рутинный контроль в простой и понятный процесс, который экономит время и предотвращает бытовые конфликты.

## North Star Metric

**Основная метрика:** количество успешных проверок уборки в неделю.

Дополнительные метрики:

- Процент возвращающихся пользователей: ≥ 40%
- Среднее время получения оценки: < 15 секунд
- Точность определения загрязнений: ≥ 90%
- Удовлетворенность пользователей (NPS): ≥ 30
